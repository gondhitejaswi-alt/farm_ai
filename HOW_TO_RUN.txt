 Farm AI — How to Run (Step by Step)
══════════════════════════════════════════════════════

STEP 1: Open Command Prompt (CMD) or Terminal

STEP 2: Go to the farm_ai folder
  cd C:\Users\Gowtham\Downloads\farm_ai

STEP 3: Install requirements (first time only)
  py -m pip install streamlit plotly pandas requests numpy

  For CNN leaf scan (optional but recommended):
  py -m pip install tensorflow pillow

STEP 4: Run the app
  py -m streamlit run dashboard/streamlit_app.py

STEP 5: Open browser at http://localhost:8501

══════════════════════════════════════════════════════
  API Keys — Already set in .env file!
══════════════════════════════════════════════════════

The .env file already has:
  ✅ OPENWEATHER_API_KEY  → Real weather (temp, rain, humidity)
  ✅ DATA_GOV_KEY         → Real mandi prices from govt API

You will see 🟢 LIVE Data in the sidebar when APIs work.
If you see 🟡 Demo Data, check:
  1. Is DEMO_MODE=false in .env? (not true)
  2. Do you have internet connection?
  3. Is .env file inside the farm_ai/ folder (same level as agents/, dashboard/)
